# 💳 Credit Card Approval Prediction

An end-to-end Machine Learning web application designed to automate the evaluation of credit card applications. By analyzing key socio-economic factors, the system classifies applicants as low-risk (Approved) or high-risk (Rejected) in real time and provides tailored financial recommendations.

---

## 🚀 Live Application

*   **App Link**: [https://credit-card-approval-prediction-g2p5.onrender.com/](https://credit-card-approval-prediction-g2p5.onrender.com/)

---

## ✨ Features

*   **Real-Time Risk Profiling**: Instant application assessment with exact approval probability scores.
*   **Custom Recommendation Engine**: Dynamic feedback showing users how to improve their credit rating (e.g., income limits, job tenure, asset collateral).
*   **Modern UI/UX**: Responsive glassmorphic layout, clean typography, and interactive components.
*   **Secure Session Architecture**: Secure session state tracking and active Cross-Site Request Forgery (CSRF) protection.

## 🧠 Machine Learning Model

*   **Algorithm**: Gradient Boosting Classifier.
*   **Inputs**: Gender, Car Ownership, Property Ownership, Income, Income Type, Education Level, Family Status, Housing Type, Age, Employment Duration, and Family Size.
*   **Feature Pipeline**: Automated handling of missing data, scaling, and categorical one-hot encoding using Scikit-Learn Pipelines.
